# رهیار مطالعه | Study Tracker
اپلیکیشن آفلاین فارسی برای ثبت نشست‌های مطالعه، کتاب‌ها و ارزیابی فصل‌ها. داده‌ها در SQLite محلی دستگاه ذخیره می‌شوند.

## پیش‌نیاز ساخت APK
Flutter SDK پایدار (Dart مطابق pubspec)، Android Studio و Android SDK/platform tools. پروژهٔ Android با `flutter create` ایجاد شده و این پوشه فایل‌های `lib` و مانیفست را جایگزین کرده است.

## ساخت APK با Flutter
1. آرشیو را استخراج کنید و در پوشهٔ `study_tracker_flutter` ترمینال باز کنید.
2. `flutter doctor` اجرا و هر مورد Android SDK/مجوز را برطرف کنید.
3. `flutter pub get`
4. `flutter create . --platforms=android` (در صورت نبود فایل‌های Gradle)؛ سپس بررسی کنید مانیفست ما در `android/app/src/main/AndroidManifest.xml` حفظ شده باشد.
5. `flutter run` برای اجرا روی دستگاه/شبیه‌ساز؛ برای APK قابل نصب: `flutter build apk --release`.
6. خروجی `build/app/outputs/flutter-apk/app-release.apk` است. انتقال فایل به Android و تأیید نصب از منبع ناشناس لازم است.

## Android Studio
پوشه را باز کنید، Flutter/Dart plugins و SDK را نصب کنید، سپس در Terminal دستورهای بالا را اجرا یا از Build > Flutter > Build APK استفاده کنید.

## پیش‌نمایش فوری، بدون Flutter
فایل `offline_preview.html` را در مرورگر باز کنید. اطلاعات نسخهٔ وب در localStorage همان مرورگر ذخیره می‌شوند؛ از Export برای نسخهٔ پشتیبان استفاده کنید. برای نصب میانبر روی موبایل، HTML را روی گوشی باز کنید و از منوی مرورگر Add to Home Screen / افزودن به صفحه اصلی را انتخاب کنید. فایل را به‌صورت محلی باز کنید؛ قابلیت‌ها و ماندگاری localStorage به محدودیت‌های مرورگر بستگی دارد. برای PWA قابل نصب از شبکه/آفلاین واقعی باید فایل روی HTTPS میزبانی شود و service worker فعال باشد.

## نکته‌های پیاده‌سازی
- ساعت شروع و پایان نشست به‌صورت ISO-8601 و زمان محلی دستگاه نگه‌داری می‌شود؛ UI تاریخ جلالی را نمایش می‌دهد.
- پیوست‌های انتخابی تصویر/صوت به‌صورت مسیر فایل ثبت می‌شوند؛ حذف/جابجایی فایل خارج برنامه ممکن است پیوست را غیرقابل‌دسترس کند. افزودن فایل صوتی صرفاً انتخاب فایل است و ضبط درون‌برنامه‌ای در این نسخه پیاده‌سازی نشده.
- permissionهای Android اعلام شده‌اند. برای نسخهٔ انتشار، امضای APK را با keystore خود پیکربندی کنید.
